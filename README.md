# Terranova Pet Memorial & Rede Social

Plataforma integrada da **Terranova Pet**: Identificação Inteligente, Cemitério Pet Virtual Coletivo (Jardim das Estrelinhas) e Rede Social & Diário de Aventuras.

## 🐾 Estrutura de Arquivos
- **`social.html`**: Rede Social e Diário de Aventuras dos Pets vivos (Feed estilo Instagram, Stories 9:16 com passador e ajuste automático de fotos, envio de patinhas, comentários, exclusão de posts/stories e edição completa de perfil).
- **`mural.html`**: Cemitério Pet Virtual Coletivo (Jardim das Estrelinhas com paleta solene em Roxo Nobre e Dourado Celestial, jazigos em mármore creme, acendimento de velas e filtros por espécie).
- **`memorial.html`**: Memorial individual personalizado com fotos, biografia e velas eternas.
- **`gerador.html`**: Ferramenta interativa de geração de tags e QR Code para coleiras inteligentes Terranova Pet.
- **`index.html`**: Portal central integrando todos os serviços.
- **`server.js`**: Servidor web local Node.js.

## 🚀 Como Iniciar:
Execute:
```bash
node server.js
```
E abra no navegador em: `http://localhost:3000`
